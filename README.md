# 短信清理 · Android

为 OPPO Reno10 Pro 5G 的批量短信整理需求制作的**临时清理工具**。中文界面，本地处理，无联网权限、广告或分析 SDK。Android 11+。

## 功能

- 正文关键词 + 发件号码/标识组合查询，按字面匹配，`%` 和 `_` 不视为通配符。
- 点击短信查看全文，并快捷筛选同发件人（包含匹配）。不查联系人姓名。
- 全选当前查询的全部结果、逐条选择/取消、确认后批量删除。
- 查询改变后清空选择，删除按短信 ID 执行，不整段删除会话。
- 所选短信导出 JSON，使用系统文件选择器，不需要全部文件访问权限。
- JSON 仅用于保存/查看，本版本**不提供恢复导入**。

## 重要安全限制（安装前必读）

Android 只允许默认短信应用写入/删除系统 SMS。只读查询无需默认角色，但需要用户授予读取短信权限。ColorOS 可能另有短信/后台权限限制，**尚未在 OPPO 真机验证**。

这不是完整的默认短信客户端：**不支持 MMS 下载、RCS、发送短信及通话快捷回复**。成为默认期间，这些功能可能失效，MMS 甚至可能丢失。不要长期设为默认，不要用于紧急通信。本应用会保存默认期间收到的普通 SMS 到系统收件箱，但尚未经双卡真机验证。

推荐安全流程：
1. 先在原应用备份重要短信，记住原默认短信应用名称。
2. 本应用授予读取权限，查询、选择、导出 JSON。建议把备份保存在本机，不要上传私密短信。
3. **先开启飞行模式**，然后点击删除按钮，阅读风险并通过系统弹窗临时指定默认。应用不会替你更改系统设置。
4. 角色切换后重新查询/选择；再次点击删除，核对数量并确认。删除是永久操作，无法撤销。
5. **立即恢复原默认短信应用**（底部提供设置入口），确认恢复后再关闭飞行模式。

飞行模式检查只能降低风险，不保证系统无法通过 Wi-Fi calling 收到消息，也不能阻止用户在后台关掉飞行模式。若不能接受任何收信影响，勿授予默认角色，只使用查询/导出功能。

短信权限属于受限制权限；部分设备或安装器可能需要额外允许，若普通安装无法授权，请不要通过来路不明的提权工具绕过。先检查系统“应用权限/默认短信应用”。

## 构建

依赖 JDK 17、Gradle 8.10.2、Android SDK platform 35 + build-tools 35.0.0。

```sh
bash scripts/test-filters.sh
gradle lintDebug assembleDebug assembleRelease
```

此仓库使用系统 Gradle，未内置 wrapper。CI 固定 Gradle 版本并安装 SDK。

## GitHub 自动构建与发布

`.github/workflows/android.yml` 在 main 推送、PR、`v*` 标签、手动触发和 Release 发布时构建，执行过滤测试和 Android lint。Actions Artifacts 提供 APK 与 lint 报告；发布 GitHub Release 后，会自动把 APK 附加到该 Release。

- `app-debug.apk`：可安装测试包。CI 每次可能生成不同 debug 签名，不能保证覆盖升级；卸载会清空应用自身状态，不会删除系统短信。
- `app-release-unsigned.apk`：未签名正式包，**不能直接安装**，用于自行正式签名。
- 没有把私钥放进仓库，也没有伪称正式签名发布。长期使用应配置持久签名密钥后再发布正式包。不要将明文密钥提交 GitHub。

这是侧载原型，不代表符合 Google Play 短信权限上架政策。

## 验证清单

纯 Java 测试覆盖中文、空条件、SQL 通配符转义、反斜线和引号。CI 运行 lint + debug/release 构建。

真机发布前必须验证：首次拒绝/授予读取权限；角色申请取消；查询交集与全部结果选择；删除取消和部分失败；JSON 取消/导出；旋转屏幕；大短信库；默认角色丢失；普通 SMS/双卡接收；恢复原应用。MMS/RCS 不在本版本支持范围。
